

# MARMoT

A repository of scripts, tools, configurations and experiments in the MARMoT project.


* [`make`](make/README.md): makefiles for running experiments with MAMMOTH
* [`data`](data/README.md): datasets data preparation pipelines
* [`tokenizer`](tokenizer/README.md): tokenization models and tokenizer training scripts
* [`models`](models/README.md): registry of trained MAMMOTH models and their scores
* [`dashboard`](dashboard/README.md): web dashboard for plotting model scores
* [`eval2`](eval2/README.md): make-driven evaluation pipeline for trained models
* [`tools`](tools/README.md): conversion scripts and a small SLURM framework
* [`sandbox`](sandbox/README.md): playground for testing models, tools and pipelines
