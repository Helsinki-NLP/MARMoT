

# MARMoT

A repository of scripts, tools, configurations and experiments in the MARMoT project.


* [`make`](make): makefiles for running experiments with MAMMOTH
* [`data`](data/README.md): datasets data preparation pipelines
* [`tokenizer`](tokenizer/README.md): tokenization models and tokenizer training scripts
* `tools`: scripts and tools used in some experiments
* `sandbox`: playground for testing models, tools and pipelines
